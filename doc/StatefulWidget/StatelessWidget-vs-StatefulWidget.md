# StatelessWidget vs StatefulWidget

## 比較表

|                    | StatelessWidget      | StatefulWidget                                      |
| ------------------ | -------------------- | --------------------------------------------------- |
| **状態**           | 持てない             | 持てる                                              |
| **再描画**         | 親が変わったときだけ | `setState()` で自分から                             |
| **初期化**         | できない             | `initState()`                                       |
| **クリーンアップ** | できない             | `dispose()`                                         |
| **メソッド**       | `build()` のみ       | `initState()`, `dispose()`, `build()`, `setState()` |
| **用途**           | 固定表示             | 動的な画面                                          |

## メソッドの有無

| メソッド      | StatelessWidget | StatefulWidget |
| ------------- | --------------- | -------------- |
| `initState()` | ❌              | ✅             |
| `dispose()`   | ❌              | ✅             |
| `setState()`  | ❌              | ✅             |
| `build()`     | ✅              | ✅             |

---

## ライフサイクルの違い

### StatelessWidget

```
1. ウィジェット作成
   ↓
2. build() 呼ばれる
   ↓
3. 親が変わったら build() 再実行
   ↓
4. ウィジェット削除
```

---

## 選び方

- 状態が変わらない
- プロパティを表示するだけ
- 例: ヘッダー、アイコン、カード、ラベル

## 重要ポイント

### StatelessWidget

- プロパティは持てるが変更不可（`final`）
- 自分から再描画できない（親に依存）
